# YSFlight Mod

This repository contains my personal modifications to
YSFlight Community Edition (YSCE).

The project is based on YSCE, with additional changes
and experiments in flight physics and rendering.

This repository is not an official YSCE project.

# New Features

# Flight Physics Improvements

Improved aircraft ground behavior on sloped terrain.

Reduced excessive bouncing when moving downhill.

Improved tailstrike detection.

# Controls and Navigation

Fixed ILS/VOR selection bug (key 6).

Added game speed control (- / +).

Added incremental viewpoint adjustment using keyboard controls.
